# XSource Security

Continuous AI security testing for companies that ship AI. Independent, based in Christchurch, New Zealand.

* **Continuous AI Security:** ongoing AI red teaming and AI penetration testing for one AI application on an agreed testing schedule. Model, prompt, tool and integration changes are retested within an agreed scope.
* **AI Security Assessment:** a one-off 1 to 2 week assessment of a chatbot, AI agent or LLM feature, with a written report.

Every finding is reproduced and delivered with evidence and written remediation.

**Research:** source-level audits of AI infrastructure, firmware and cryptography. Public record: 10 published CVEs (Lenovo BIOS SMM, Mbed TLS, the CROSS post-quantum signature scheme and the vLLM inference server), six security fixes authored and merged upstream, including the Linux kernel, and seven TF-RMM fixes merged with Reported-by credit.
