# XSource Security

Independent security research firm, Christchurch, New Zealand. Source-level security audits and penetration testing for AI infrastructure, firmware and cryptography.

* **AI infrastructure:** inference servers, LLM gateways, application platforms, RAG pipelines, agents and MCP
* **Firmware and accelerators:** UEFI/SMM, ARM TrustZone, TF-A/TF-M, secure boot chains, NPU and GPU drivers
* **Cryptography and PQC:** post-quantum and classical implementations, TLS stacks, signature verification

Every finding is reproduced against the build in scope and delivered with evidence and written remediation.

**Public record:** 10 published CVEs (Lenovo BIOS SMM, Mbed TLS, the CROSS post-quantum signature scheme and the vLLM inference server), six security fixes authored and merged upstream, including the Linux kernel, and seven TF-RMM fixes merged with Reported-by credit.
